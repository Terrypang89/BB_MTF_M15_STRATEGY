## Method

1. **Reconcile** the ~214 trades to realized $ (reuse `dissect_v36_13.py` join: sequential in/out, +/- 600s, price tie-break). Report matched + $ sum vs Tester.
2. For each trade, read the Sideways state AT ENTRY BAR: the -S_XX code if present (nearest DUALTF/STRATEGY_6 row within +/- 600s), else NONE.
3. **SPLIT**: SIDEWAY_ACTIVE (any S_XX at entry) vs SIDEWAY_NONE. Per group: n, net$, win-rate, PF.
4. **PER-CODE**: for each S_XX with n>=10 entries, report n, net$, WR, PF. Which codes are worst?
5. **COUNTERFACTUAL** (realized-only, label clearly): net$/PF of SIDEWAY_NONE alone (what blocking all sideways entries would have left).
